# UOK Fee Portal

A web-based School Fees Management System developed for the **University of Kabianga** using Django.

The UOK Fee Portal provides a digital platform for managing student records, fee assignments and payments. It aims to simplify fee administration and make financial information more accessible to students and administrators.

## Features

- **Student Registration:** Register student accounts.
- **Student Authentication:** Secure student login.
- **Student Dashboard:** Access student fee information and account details.
- **Fee Management:** Assign and manage student fees.
- **Fee Statements:** View student fee statements and outstanding balances.
- **Payment Records:** Record and manage payment transactions.
- **Payment History:** View previous payment transactions.
- **Payment Receipts:** Generate and print payment receipts.
- **M-Pesa Integration:** Daraja API Sandbox integration for STK Push payment testing.
- **Administration:** Manage student records, fee assignments and payment information.

## Technologies Used

- Python
- Django
- HTML5
- CSS3
- JavaScript
- PostgreSQL
- M-Pesa Daraja API (Sandbox)

This project was developed as an academic software development project to demonstrate how web technologies can be used to improve university fee management, payment tracking and student access to financial information.
